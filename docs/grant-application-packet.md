# Grant Application Packet

Current CoFi publishes a submission-ready Circle Developer Grant packet at `/#/grant-application` and `/api/v1/grant-application`. A Markdown export is available from `/api/v1/grant-application/markdown`.

The packet maps Current CoFi to Circle's four public selection criteria, turns the canonical grant dossier into concise application answers, includes measurable milestone acceptance evidence, and preserves direct reviewer links to public Arc testnet proof.

## Integrity

The JSON packet is canonicalized and assigned a SHA-256 digest. Tests verify the digest, answer boundaries, Markdown export, public evidence counts, and the absence of recipient identities, wallet addresses, API keys, private partner contacts, founder details, or invented funding amounts.

## Honest completion boundary

Current CoFi can complete the product narrative, technical architecture, shipped scope, evidence ledger, roadmap, and proposed milestones without outside help. Founder biographies, legal entity details, private contact information, and a requested USDC amount require applicant input. Named pilots, an independent audit, Arc mainnet production availability, and token legal review remain external gates.

The official Circle application page was observed as closed on August 1, 2026. The packet does not imply that submissions are open; it keeps the project ready for the next application window.
