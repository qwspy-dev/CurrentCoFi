# Gateway Unified Balance Funding

Current CoFi can move finalized Circle Gateway USDC into an Arc campaign without pretending a smart-account signature is Gateway-compatible.

## Operator flow

1. A project chooses an unfunded USDC campaign and a supported deposit network.
2. Current creates a dedicated Circle user-controlled EOA for Gateway operations. The recipient's normal Arc wallet remains a gas-sponsored SCA.
3. The EOA approves the official Gateway Wallet and calls `deposit(address,uint256)`. Current never sends USDC directly to the Gateway Wallet contract.
4. Current reads finalized balances from the public Gateway `/v1/balances` endpoint and shows the consolidated USDC total.
5. Current creates an EIP-712 `BurnIntent`, requests user approval through Circle, receives the signature in the browser, and verifies the recovered signer on the server.
6. The verified intent is submitted to Gateway. The returned attestation and operator signature are persisted as evidence.
7. The Arc SCA calls `gatewayMint(bytes,bytes)` through a user-approved Circle transaction.
8. The project approves USDC and fully funds the Current campaign vault. The distribution becomes claimable only after that final Arc transaction is confirmed.

## Recovery and evidence

Every intent is durable and resumes from its latest confirmed state. Stored evidence includes the source chain and domain, EOA address, deposit transaction, signed typed-data payload, recovered signer, Gateway transfer identifier or direct-attestation record, Arc mint transaction, and campaign-vault funding transaction.

The project SDK exposes read-only Gateway proof through `current.gateway.list()`. Webhooks cover creation, deposit, attestation, Arc arrival, and campaign funding. Grant evidence schema `current-evidence-v6` includes the complete Gateway route without exposing recipient identities or private signing material.

## Security boundaries

- Gateway burn intents use an EOA because Gateway currently accepts EOA signatures.
- The typed-data signature is checked against the persisted operator address before Gateway submission.
- Private keys never reach Current CoFi; Circle's user-controlled wallet approval remains on the user's device.
- The Arc destination can remain an SCA, preserving sponsored transactions for campaign settlement.
- A fee reserve is deposited alongside campaign principal. The UI separates principal, maximum Gateway fee, and campaign-vault proof.
- Direct USDC transfers to the Gateway Wallet are never generated by Current CoFi.
